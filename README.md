# Lumina TV

A televisão do mundo, ao seu alcance. Player IPTV web (País · Categoria · Busca · Favoritos),
para TV e navegador. Toca apenas streams públicos/oficiais.

- App: `index.html`
- Base de canais: `lumina.m3u` — ao atualizar este arquivo no Git, o app se atualiza sozinho
  (a cada ~12h ou no botão "Atualizar agora").
- Site (após ativar Pages): https://mmbussacarini.github.io/luminatv/
